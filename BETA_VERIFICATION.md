# Приёмка сокращённого бета-теста Ватэс

Дата: 31 октября 2026 года. Основа: `tea-app-beta-empty-2026-10-31.zip`.

## Результат

Сборка Next.js 16.2.12 и проверка TypeScript прошли. Выполнены 22 проверки API, первого входа и браузерных сценариев. Ошибок JavaScript в проверенных сценариях не было. Данные приёмки удалены перед упаковкой.

## Что изменено

- Новые сотрудники создаются готовыми к входу. Старые записи с незавершённой активацией проходят обычную проверку пароля и входят без дополнительной регистрации.
- Из обеих форм входа убрана регистрация, из профиля и его просмотра администратором убраны почта, телефон и соцсеть.
- Имя, аватар, роли, пароль и учебные функции сохранены. API профиля не сохраняет исключённые контактные поля; совместимое хранилище применяет тот же фильтр.
- Обычные сообщения и сообщения о документах сохраняются через `POST /api/notifications`. Дедлайны остаются задачами кабинета.
- Новое сообщение и очистка своего списка не стирают чужие личные уведомления.
- Надпись «Отправить уведомление» сохранена; файл компонента кнопки совпадает с базовой бета-копией.
- Алгоритмы отправки писем и Push, браузерная подписка, обработка внешних Push в Service Worker, настройки SMTP/VAPID и четыре соответствующие зависимости удалены.
- Старые маршруты регистрации и внешней доставки отвечают HTTP 410 без отправки сообщения и без проверки почтового домена.
- Пустые материалы, отсутствие встроенных паролей и невидимые реквизиты базовой бета-копии сохранены.

Дополнительная статическая проверка подтвердила отсутствие контактных полей ввода, активных вызовов отключённых каналов и их зависимостей в manifest и lock-файле.

ESLint сравнен с базовой бета-копией для 23 изменённых файлов TypeScript/TSX: новых замечаний по правилам нет, общее число замечаний снизилось с 361 до 288. Прежние замечания проекта не устранялись в рамках этой задачи; весь проект не объявляется свободным от ошибок ESLint.

## Запуск и границы проверки

Порядок настройки первого администратора и запуска указан в `BETA_README.md`. Рабочие пароли и секреты в архив не включены.

SMTP и доставка Push в этой версии отсутствуют. Проверка почтового домена для входа не нужна. Внешний AI и MySQL в этой приёмке не подключались; их настройка, если она понадобится, остаётся отдельной задачей. Действующий сервер и предыдущий ZIP не изменялись.
